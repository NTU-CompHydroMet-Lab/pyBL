# pybl

Top-level package. Imports all submodules and exposes `classic_statistics` directly.

```python
import pybl
```

## Submodules

| Module | Description |
|--------|-------------|
| [`pybl.models`](pybl.models.md) | BLRP model classes and parameters |
| [`pybl.raincell`](pybl.raincell.md) | Rain cell intensity distributions |
| [`pybl.timeseries`](pybl.timeseries.md) | Time series data structure |
| [`pybl.utils`](pybl.utils.md) | Statistics and utility functions |
