# pyBL

**pyBL** is a Python implementation of the Bartlett-Lewis based model for stochastic rainfall simulation.

## Overview

The Bartlett-Lewis rectangular pulse (BLRP) model is a stochastic point process model widely used in hydrology for generating synthetic rainfall time series. pyBL provides a fast, type-annotated implementation suitable for research and engineering applications.

## Features

- Bartlett-Lewis rectangular pulse model variants (BLRP, BLRPRx)
- Fast numerical computation via Numba JIT compilation
- Time series aggregation utilities
- pandas-native data interfaces
